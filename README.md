# InnovateX 2026

A fictional college-fest website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop/tablet/mobile layout
- JavaScript countdown timer
- Interactive expandable event cards
- Day-wise event timeline
- Responsive image gallery
- Registration form with name, email and event validation
- Success message after valid submission
- Original dark/neon visual design

## Files
- `index.html` — page structure/content
- `style.css` — responsive styling
- `script.js` — countdown, navigation, cards and form validation

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Go to Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for the Pages URL to appear.

## Important
The gallery currently uses remote Unsplash image URLs. For a fully self-contained submission, download/replace these with local images in an `assets` folder.
